# Developer Reference

> **For developers.** This page is the one place we get technical — contract
> addresses, parameters, and build commands. If you're just here to get paid,
> you can safely skip it.

> Contract addresses come from your own deployment. Run
> `pnpm deploy:testnet` (with `DEPLOYER_PRIVATE_KEY` set), which writes fresh
> addresses to `web/.env.local`.

## Contracts

| Contract | Purpose |
| --- | --- |
| `MaweeRegistry` | `@username` → owner, note public key, viewing public key |
| `MaweePool` | Shielded USDC pool: Poseidon Merkle tree, nullifiers, Groth16 verification |

## Pool & privacy parameters

| Key | Value |
| --- | --- |
| Merkle tree depth | `20` (fixed by the circuits) |
| Root history | last `30` roots accepted |
| Proof system | Groth16 over BN254 (EVM precompiles) |
| Hash | Poseidon (shared across circuit / contract / browser) |
| Deposit public signals | `[commitment, amount]` |
| Withdraw public signals | `[root, nullifier, recipient, amount]` — `recipient = uint160(address)` |
| Transfer public signals | `[root, nullifier, outCommitmentRecipient, outCommitmentChange]` |
| Admin powers | pause/unpause, two-step admin transfer; no upgrades, no fund movement |

Public (`NEXT_PUBLIC_*`, baked into the browser bundle):

| --- | --- |
| `NEXT_PUBLIC_MONAD_CHAIN_ID` | `10143` testnet, `143` mainnet, `31337` local Hardhat |

| `NEXT_PUBLIC_MAWEE_POOL_DEPLOY_BLOCK` | First block the indexer scans |

| `NEXT_PUBLIC_USDC_MINTABLE` | `true` when the asset is the testnet MockUSDC |
| `NEXT_PUBLIC_PRIVY_APP_ID` | Privy app (client) |

Server-only (never committed):

| Variable | Purpose |
| --- | --- |
| `MONGODB_URI` | MongoDB connection string (users, links, indexer cache) |
| `CRON_SECRET` | Bearer token for `/api/cron/pool-indexer` |
| `PRIVY_APP_ID` / `PRIVY_APP_SECRET` | Server-side Privy token and wallet verification |
| `MONAD_LOGS_BLOCK_RANGE` | Max blocks per `eth_getLogs` call (default `100`) |

## Prerequisites & build

* Node 20+, pnpm 10+
* circom 2 and snarkjs (only to rebuild circuits)
* MongoDB

```sh
pnpm install                                   # web + contracts
pnpm contract:test                             # Hardhat suite with real proofs
DEPLOYER_PRIVATE_KEY=0x… pnpm deploy:testnet   # deploy + write web/.env.local
pnpm --filter web migrate:up                   # Mongo indexes
pnpm dev                                       # http://localhost:3000
```

Rebuilding circuits (`cd circuits && ./build.sh`) also regenerates the Solidity
verifiers via `pnpm --filter contracts verifiers`. Redeploy the pool afterwards.
